1. introduction
    Quantize_parameter_test.py:A script (currently in experimental testing) for traversing all currently supported quantization algorithm parameters.
    The current script lists the parameters of quantization algorithms such as 'min-max','kl_asymm_divergence','kl_symm_divergence','percentile','moving-avg',
'mle' and so on. While traversing these quantization parameters, we save the model transformed/quantized midtier IR as a quantized tflite model and use 
the input corresponding to the original model provided. In the npy file, the quantized tflite is deduced forward, and then compared with the output npy of
the original model, and the cosine similarity, Euclidean distance and other indicators are output.If the customer's model has other judgment indicators, such
as SNR, MSE, etc., it can also be modified based on the script.

3. application suggestion
    Because the current script is still in the experimental testing stage, I will provide some suggestions for use
    3.1.Inputs to the original model are provided:
        a.Directly select a single image after the pre-processing to save the npy file, and run out the original model should be input output results, as a script comparison file.。

    3.2.Optimal parameter filtering suggestions
        The optimal parameters selected by this script may not be completely proportional to the results of the model transformed by using the optimal parameters through the complete verification set test.
        In the existing tests, some models can screen out the optimal parameters through this script, and some models may not have the optimal performance on the verification set.
        suggest：
            3.2.1. If the validation set data of the model is not large, it is recommended to integrate the validation code in the run_tflite interface, and then directly save the results of the validation set.
                This kind of quantization conversion parameter based on verification set screening is real and effective.

            3.2.2. Parametric search suggestion：
                The first way：
                   a、Modify quantize_algos parameter information to set the two groups of parameters as self.quantize_algos=['min-max'],self.weights_quantize_algos=['min-max'], At this time, the quantization
                      effect of different data sets is iterated and one optimal quantization parameter iterations under min-max quantization is selected first.
                   b、Change the value of self.iteration to the optimal value found in step a. quantize_algos=["min-max","percentile","hist_percentile","hist_asymm_percentile","moving-avg","his_moving_avg",
                      " kl_asymm_divergence","kl_symm_divergence"],self.weights_quantize_algos=['mle','min-max'] Performs a second search.
                The second way:
                    According to experience, the algorithm parameters that perform well for most classification models are set to:
                    self.quantize_algos=["percentile","hist_percentile","hist_asymm_percentile"]
                    self.iterations = [100]
                    self.weights_quantize_algos=['mle']
                    These algorithms are integrated in Quantize_optimization_tool_simple_version.py, and you can run this simple version of the script directly for searching.
                    For target detection models, such as yolovs and other models, the data set parameter is set to self.iterations = [10], and the model has better precision performance.
                The third way:
                    Run the script Quantize_optimization_tool.py directly to traverse the search.
